# 📦 **String Transformer**

A fast, dependency-free tool that transforms text into 50+ formats: naming
conventions, encodings, ciphers, hashes, dev tools and text utilities. Runs
entirely in the browser (or in Node via the CLI/library) — nothing you type is
ever sent to a server.

This project is ideal for developers who want to:

* Convert text between camelCase, snake_case, kebab-case and 10+ other naming conventions
* Encode/decode Base64, URL, hex, Unicode escapes, JSON strings, Morse code
* Hash text with SHA-1/256/512, decode a JWT payload, or run classic ciphers (ROT13, Atbash, ROT47)
* Clean up multi-line text (dedupe, sort, trim empty lines)
* Do all of the above from the command line or as a package dependency

## ✨ Features

* 50+ transformation modes across 8 categories (Basic, Naming Conventions,
  Encoding, Ciphers & Codes, Hashing, Dev Tools, Text Tools, Fun)
* Searchable, categorized transformer picker (`Ctrl`/`Cmd`+`K` to focus it)
* Live transform as you type, with a real error message when the input
  doesn't match the expected format (e.g. invalid Base64)
* Swap (⇄) button to flip between a transformer and its inverse
* Auto-detection suggestion ("This looks like Base64, switch?")
* Character counters, copy-to-clipboard feedback, light/dark theme toggle
* Shareable deep links (`#camelCase`) and a dedicated landing page per
  transformer for search engines (`/t/<name>/`)
* Fully Unicode-safe: accented letters, `€`, emoji and other multi-byte
  characters round-trip correctly through binary/Base64/hex
* Vanilla JavaScript — zero runtime dependencies, works offline as a PWA
* Usable as a CLI (`pnpm dlx string-transformer`) or as a library

## 🧩 How It Works

1. Pick a transformer from the search menu (or follow a deep link like `#slugify`)
2. Type or paste your input — the output updates live
3. If the input doesn't match what the mode expects, an inline error explains why
4. Use ⇄ Swap to jump to the inverse transform, or Copy Output to grab the result

## 🛠️ Development

```bash
git clone https://github.com/nandomunoz/string-transformer
cd string-transformer
pnpm serve       # static files, any local server works
pnpm test             # node --test — no dependencies required
pnpm build:seo   # (re)generates the /t/ landing pages, sitemap.xml, robots.txt
```

### As a library / CLI

```bash
pnpm dlx string-transformer camelCase "hello world"   # -> helloWorld
echo "hello" | pnpm dlx string-transformer sha256
```

```js
import { strTo, transformers } from "string-transformer";

const { ok, value, error } = await strTo({ mode: "slugify", str: "Café!", transformers });
```

## 🧪 Adding a new transformer

1. Add a pure `(str) => string | Promise<string>` function in the relevant
   module under `src/js/modules/` (throw `FormatError` for invalid input)
2. Register it in `src/js/core.js`
3. Add its UI copy (`title`, `description`, `category`, ...) to `src/js/data/msg.js`
4. If it has an inverse, register the pair in `src/js/data/opposites.js`
5. Add a test in a co-located `*.test.js` file

See [AGENTS.md](AGENTS.md) for the full architecture notes and
