Frequently asked questions

Is my text uploaded anywhere?

No. Every conversion runs in your browser, in plain JavaScript. Nothing you type is sent to a server, logged or stored, so it is safe for tokens, keys and drafts.

Does it work offline?

Yes. After your first visit the app is cached, so it keeps working without a connection. You can also install it from the Install app button and open it like any other app.

Does it handle accents, emoji and other alphabets?

Yes. Encoders and decoders work on real UTF-8 bytes, so characters like á, ñ, € and emoji convert correctly, not just plain ASCII.

How do I convert the result back?

Use the Swap button. It switches to the opposite transformer, for example Base64 decode after Base64 encode, and moves the result into the input.

Can it tell which format my text is in?

Often, yes. If your input looks like Base64, hex, a JWT or Morse code, the converter suggests the matching transformer with one click.

Can I use SHA-256 and the other hashes for passwords?

No. SHA-1, SHA-256 and SHA-512 are fast checksums, fine for comparing files or text but not for storing passwords. Use a slow password hash such as Argon2 or bcrypt for that.

Is it free? Is there a limit?

It is free, with no sign-up and no limit on how much text you convert. The code is MIT licensed and lives on GitHub.

Is there a command-line version?

Yes. The repository includes a CLI: run node bin/cli.js with a format and your text, or pipe text in. Run it with --list to see every format.
